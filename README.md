# Base Nexo — site

Página de vendas das listas de leads B2B extraídas da base aberta de CNPJ da Receita Federal.

- `index.html` — página única, sem dependências além do Google Fonts.
- Formulário de amostra monta um `mailto:` para contato@basenexo.com.br (nada é armazenado).

Publicar: `git push` na branch `main` (GitHub Pages serve a raiz).
